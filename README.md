# Сэйлон — hot landing

Сокращённая версия маркетингового сайта Сэйлона для тёплой и горячей аудитории. Это отдельный Next.js-проект: исходный cold-site, его репозиторий и production-домен не изменяются.

## Структура страницы

1. Hero
2. Почему ответы уместны
3. Управляемый путь клиента
4. Характер общения
5. Контроль ответа
6. Живая демонстрация
7. Каналы и самостоятельный запуск
8. Бесплатный тест и тарифы
9. Короткий FAQ
10. Финальный CTA

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверка

```bash
npm run lint
npm run typecheck
npm run build
```

## Интеграции

До подключения CRM заявки отправляются на рабочую электронную почту через `mailto:`. Онлайн-оплата на сайте не принимается. Тарифы указаны без НДС.
